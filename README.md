#  FitLog — Workout Library

FitLog is a modern workout tracking web application built with Next.js. It allows users to explore different workouts, view detailed exercise information, create a personal workout plan, and save their favorite exercises.

##  Technologies Used

* ** Next.js ** — React framework for building the application
* ** React ** — Building reusable UI components
* ** JavaScript ** — Application logic and functionality
* ** Tailwind CSS ** — Styling and responsive design
* ** REST API ** — Fetching workout data
* ** LocalStorage ** — Saving workout plans and favorite exercises

##  Key Features

1. ** Workout Library **
   Browse a collection of workouts with information such as muscle groups, equipment, duration, calories, and rating.

2. ** Workout Details **
   View detailed information about each workout, including sets, reps, difficulty, instructions, and calories.

3. ** Personal Workout Plan **
   Add workouts to **Today's Plan** and manage your selected exercises in one place.

4. ** Save Favorite Workouts **
   Save workouts for later and easily access them from the saved workouts section.

5. ** Responsive Dark UI **
   A modern dark-themed interface that works smoothly across desktop, tablet, and mobile devices.

##  Project Purpose

FitLog was created as a frontend project to practice **Next.js, React, API integration, reusable components, state management, routing, and responsive UI development**.
